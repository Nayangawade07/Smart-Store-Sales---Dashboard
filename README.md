 📊 Smart Store Data Analysis Dashboard (Excel)



 
📌 Project Overview
The **Smart Store Data Analysis Dashboard** is an interactive Excel-based dashboard designed to analyze store sales, customer demographics, order status, sales channels, and geographical performance.

The dashboard helps transform raw sales data into meaningful insights using Excel Pivot Tables, charts, and interactive filters. It provides a clear overview of business performance and helps understand sales trends, customer behavior, and order distribution.



 🎯 Project Objectives

- Analyze overall sales performance.
- Compare sales between male and female customers.
- Track order status, including delivered, cancelled, returned, and refunded orders.
- Analyze sales performance across different states.
- Understand customer demographics based on age groups and gender.
- Monitor monthly sales and order trends.
- Analyze sales channels and customer purchasing patterns.
- Support data-driven business decisions.



 🛠️ Tools & Technologies Used

- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Interactive Dashboard
- Slicers and Filters

 📊 Dashboard Features

 1. Sales Analysis by Gender
- Compares sales generated by male and female customers.
- Helps identify which customer segment contributes more to revenue.

 2. Order Status Analysis
Analyzes orders based on different statuses:

- Delivered
- Cancelled
- Returned
- Refunded

This analysis helps understand order completion and customer satisfaction patterns.

 3. State-Wise Sales Analysis
- Examines sales performance across different states.
- Identifies high-performing geographical markets.
- Helps understand regional sales distribution.

 4. Age Group and Gender Analysis
- Analyzes customers across different age groups.
- Compares male and female customer distribution.
- Helps identify important customer segments.

5. Sales Channel Analysis
- Analyzes orders across different sales channels.
- Helps understand where customers prefer to purchase products.

 6. Monthly Sales and Order Analysis
- Tracks monthly sales amount.
- Compares the number of orders across different months.
- Identifies monthly sales trends and changes in order volume.



📈 Key Insights

Based on the dashboard data:

- **Female customers** contributed higher sales than male customers.
- The number of delivered orders was significantly higher than cancelled, returned, and refunded orders.
- Maharashtra was the leading state among the states displayed in the state-wise sales analysis.
- Customer sales and order distribution can be analyzed across Adult, Senior, and Teenager age groups.
- Monthly sales and order counts varied throughout the year.
- The dashboard provides insights into customer demographics, sales performance, and order trends.
